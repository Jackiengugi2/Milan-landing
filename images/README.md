# Photos

Each photo box on the pages loads `images/<slot>.jpg` automatically. Until a file exists, the box shows a labelled placeholder.

| File | Where it appears |
|---|---|
| `hero.jpg` | Main hero (portrait/square). Also used as the social share image. |
| `register-side.jpg` | Beside the form: happy learners in the play area |
| `feature-play-in-class.jpg` | Play-in-class station |
| `feature-experiential.jpg` | Experiential project |
| `feature-music.jpg` | Music room |
| `feature-stem.jpg` | STEM / robotics |
| `day-teacher-floor.jpg` | Teacher at floor level with Playgroup (portrait) |
| `day-circle.jpg` | Circle time |
| `day-outdoor.jpg` | Outdoor play area |
| `thanks-hero.jpg` | Thank-you page header |
| `activity-play-stations.jpg`, `activity-experiential.jpg`, `activity-music.jpg`, `activity-stem.jpg` | Thank-you page activity cards |

Keep files around 1600px on the long side and under ~300 KB (JPG, quality ~75).
For the logo, save `logo.png` here and follow the comment in `index.html`.
